   CyberAuditX - Horizontal Flowchart (Fits Half A4 Landscape Page)
================================================================================

START --> Select --> Input --> Validate --> Execute --> Parse --> Categ --> 
  |
  +-> Error (No)
      |
      +-> Input (Loop)

Execute branches:
  ├-> Nmap: nmap -sV
  ├-> Nikto: nikto -h
  └-> SQLMap: sqlmap --batch
  
      (All converge to Parse)

Parse --> Categ --> Save --> Display --> Review --> AI Decision --> Export

AI Decision (Yes branch):
  ├-> Build Prompt
  ├-> Call Gemini API
  ├-> Parse JSON
  ├-> Show Analysis
  └-> Export

Export --> Another Scan? --> 
  ├-> Yes: Loop back to Select
  └-> No: END
